# 小説文体変更・執筆作業指示書 (Novel Style Guide)

## 目的
ChatGPT等の生成AIが出力しがちな「説明調で平坦な文体（眠い文体）」を、読者を世界観に引き込む「五感とプロの思考が息づく、緊張感と没入感のある文体」へとリライト・執筆するための指示書である。

---

## 1. 目指すべき文体の基本方針

1. **五感と身体性の強調（「痛い」「渇く」をリアルに）**
   - 単に「喉が渇いた」「痛かった」と事実を説明しない。
   - 「息を吸うたびに熱い空気が喉をナイフのように削っていく」「心臓が早鐘を打ち始めた」など、登場人物の肉体が受けている負荷を感覚的に描写する。

2. **保全屋・職人としての「思考のテンポ」の再現**
   - 主人公（シュウ）は元プロの設備保全屋である。状況を感情的に嘆くのではなく、「焦るな。まずは周囲。次に自分。最後に原因だ」といった、トラブル対応時の冷徹なロジックと手順（プロの思考テンポ）をモノローグや行動に反映させる。
   - 分からないことは「分からない」と割り切るプロのシビアさを出す。

3. **セリフと感情のシャープ化**
   - 無駄に長いセリフや、説明のためのセリフを徹底的に削る。
   - 登場人物同士の距離感（リナの警戒心、ミケの尊大だが愛嬌のある態度）が、短い掛け合いから伝わるようにする。

4. **状況描写の解像度向上**
   - 「古い滑車」ではなく、「木と木が擦れる不穏な音」「ピキリと亀裂が入る」など、機械や環境が発するシグナルを具体化する。

---

## 2. リライトにおける禁止事項・変換ルール

| 避けるべき表現（眠い文体） | 推奨される表現（引き込まれる文体） | 理由・効果 |
| :--- | :--- | :--- |
| 「最初に戻ってきたのは痛みだった。」 | 「世界が、強烈な痛みとともに再起動した。」 | 主人公の意識が戻る瞬間をメカニカルかつ印象的に演出する。 |
| 「なるほど、ではない。状況は何も分かっていない。」 | 「状況は最悪だ。（＋周囲への鋭い観察描写）」 | 自己ツッコミを減らし、保全屋としての即座の状況判断へ繋げる。 |
| 「水分不足。おそらく軽くない。」 | 「水分不足は確実に限界を超えつつある。」 | 切迫感をダイレクトに伝える。 |
| 「変な人」「面倒な人」の多用 | 「本当に面倒くさい人ね。……でも、合理的だわ」 | セリフの語尾やニュアンスにキャラクター性を馴染ませる。 |
| 魔法やスキルについての長文説明 | 「触れようとすると、頭の中で指先がツルリと滑るような感覚。」 | 理屈ではなく、主人公がその瞬間に覚えた「違和感」として描写する。 |

---

## 3. シーン別執筆プロンプト（リライト用指示テンプレート）

AIにリライトを指示する際は、以下の構成でプロンプトを入力してください。


あなたプロの文芸編集者、および実力派のライトノベル・SF小説家です。
以下の【原文】を、読者を強烈に引き込む文体へとリライトしてください。

■ リライト時の制約条件:
1. 説明調の地文を徹底的に排除し、主人公の「五感（痛み・渇き・疲労）」と「保全屋としての思考・ロジック」ベースの描写に切り替えてください。
2. セリフは短くシャープにし、キャラクター間の緊張感と信頼感が徐々に変化していく様子をセリフの端々に滲ませてください。
3. トラブルや失敗のシーン（ロープが切れる、炉が失敗するなど）は、その場の音や空気の変化を具体的に描写し、切迫感を出してください。
4. 主人公の特殊能力（構造解析・限定製作）を使う際は、脳へのダイレクトな負荷（激しい頭痛や目眩）をセットで描き、能力の乱用ができない緊張感を持たせてください。
