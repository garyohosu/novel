## 3. 製鉄と鍛冶の設定修正

### 3.1 第2話では製鉄を行わない

第2話では、鉄鉱石、砂鉄、鉱滓などから金属鉄を作ってはいけません。

釘と留め具の材料は、次のような既存の金属に限定します。

- 廃墟から回収した古い釘
- 曲がった金具
- 帯鉄
- 壊れた工具や設備の鉄製部品
- 錆を落とし、再加熱して利用可能な鉄片

小型の応急鍛冶炉は、少量の既存鉄材を加熱・成形するための設備です。鉱石を還元する製錬炉ではありません。

### 3.2 製鉄には大量の木炭が必要

将来、鉄鉱石や砂鉄から製鉄する場合は、次の条件が必要であることを設定へ反映してください。

- 酸化鉄を還元するための炭素源
- 還元反応と高温を維持する大量の木炭
- 木炭を継続生産できる森林または大量の木材資源
- 伐採、乾燥、製炭を行う設備と人手
- 炭窯
- 鉱石の採掘、選鉱、運搬
- 製錬炉と安定した送風
- 製錬後の鍛錬と不純物除去

鉄鉱石や砂鉄を発見しただけで製鉄可能としてはいけません。

### 3.3 灰色荒野では製鉄できない

現在の灰色荒野には森林がなく、木炭を継続生産できません。

そのため、当面の金属資源は廃墟から回収する鉄材に依存します。鉄くず、古釘、帯鉄、壊れた金具も有限の貴重品として扱ってください。

将来の製鉄は、森林のある土地の確保、持続可能な林業、製炭、運搬網、人員の確保が実現してから検討できる長期課題とします。

森林を一度伐採するだけでは持続しません。必要に応じて、植林、萌芽更新、伐採量の管理なども将来課題に含めてください。

### 3.4 木材と木炭を混同しない

本文中の燃料描写を点検してください。

- 乾燥した木材は着火、炉の予熱、粘土の乾燥などへ限定して構いません
- 鉄を鍛造温度まで加熱する主燃料は、廃墟に残った少量の木炭とします
- 生木や普通の薪を、そのまま高性能な製鉄燃料のように扱わないでください
- 木材を短時間で都合よく良質な木炭へ変えないでください
- 木炭の消費量と残量を曖昧にせず、応急鍛冶の継続回数が限られることを示してください

第2話の釘八本程度の加工は、廃墟に残った少量の木炭を消費した結果として成立させて構いません。ただし、同じ作業を無制限に繰り返せる印象を残してはいけません。

## 4. 本文の具体的な修正方針

`chapter-02-first-resident.md` を次の観点で修正してください。

1. 「製鉄」「製錬」「鍛冶」「再鍛造」の語を混同していないか確認する
2. 応急炉が鉱石製錬用ではなく、既存鉄材の加熱成形用だと分かるようにする
3. 木材を燃やせば鉄を十分に加工できるように読める箇所を修正する
4. 木炭が少量しかなく、今回の釘作りでかなり消費したことを示す
5. 鉄材が尽きかけているだけでなく、燃料も尽きかけていることを終盤で再確認する
6. 森林がないため、新たな木炭を継続生産できない問題をシュウまたはリナに認識させる
7. 鉄鉱石があっても現状では鉄を作れないと分かる短い認識を加えてよい
8. 技術説明を長く追加せず、観察、会話、資源確認へ分散する
9. 既存の場面構成、人物関係、結末を壊さない
10. 主人公名が「修一」になっている箇所は「シュウ」へ統一する

「鉄は鉱山だけの産業ではなく、森を大量に必要とする産業である」という制約が読者へ自然に伝わるようにしてください。ただし、現代の教科書のような長い解説にはしません。

## 7. 禁止事項

- 第2話で鉱石や砂鉄から鉄を製錬する
- 少量の薪だけで製鉄する
- 森林なしで木炭を大量生産する
- 《限定製作》で木炭や鉄材を生成する
- ミケの魔法で燃料問題を解決する
- 廃墟から大量の木炭や良質な鉄を追加発見する
- 応急炉を本格的な製錬炉へ変更する
- 炉の改良だけで燃料不足を解決する
- 第2話で森林や大鉱床を都合よく発見する
- 将来の製鉄問題を第2話内で解決する
- 既存設定にない新能力、希少素材、重要人物を追加する
- 修正と無関係な第1話や第3話以降を改稿する

## 9. Git作業

作業開始前に `git pull --ff-only` を実行し、リモート最新版から作業してください。

修正後は次を実施します。

1. `git status -sb` で変更範囲を確認する
2. `git diff` で本文と設定記録を確認する
3. 第2話修正以外の変更が混入していないか確認する
4. MarkdownがUTF-8であることを確認する
5. 上記成果物と `instructions/result-20260727-2.md` だけを明示的にステージする
6. コミットする
7. 現在の作業ブランチを `origin` へpushする
8. リモートへ反映されたコミットを確認する

推奨コミットメッセージ：

```text
fix: clarify ironworking fuel constraints
```

今回の作業は、コミットだけで止めずpushまで行ってください。認証などでpushできない場合は、成功したように報告せず、原因と未完了作業を `instructions/result-20260727-2.md` と完了報告へ明記してください。
